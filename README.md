# rosedrop
time passing
What it doesUniverse background – deep space with 180 twinkling stars + soft nebula glows.
Rose – procedurally drawn with SVG. The exact number of petals equals the number of days remaining until 1 Jan 2027 (including the current partial day).
One petal drops every day – when the date rolls over, the rose automatically has one fewer petal.
Live countdown – days + hours:minutes:seconds until midnight 1 January 2027.
On 1 January 2027 the rose loses its final petal and shows a gentle “Happy 2027” message.

Enjoy watching the rose slowly return to the stars.
